# PowerKick

Синтезатор бочек для Techno, Hard Techno, Schranz, Industrial и Hard Dance. Это настоящий синтез, а не сэмплер: в плагине нет ни одного записанного звука.

Форматы:

- **macOS:** AU и VST3, универсальная сборка Apple Silicon + Intel, а также отдельное приложение Standalone. macOS 10.13 и новее на Intel, macOS 11 и новее на Apple Silicon.
- **Windows 10/11 x64:** VST3 и отдельное приложение. Собрано на Mac и проверено в Wine; в настоящей Windows не проверялось.

## Установка

**Проще всего — установщики** из папки `Установщики`: `PowerKick-1.0.0-macOS.pkg` и `PowerKick-1.0.0-Windows-x64-Setup.exe`, по одному файлу на систему. Порядок — `Установщики/УСТАНОВКА.txt`.

### macOS вручную

Скопируйте файлы из папки `Сборки/macOS`:

- `PowerKick.component` → `~/Library/Audio/Plug-Ins/Components/` (AU для Logic Pro)
- `PowerKick.vst3` → `~/Library/Audio/Plug-Ins/VST3/` (Ableton, FL Studio, Cubase, Studio One, Reaper)
- `PowerKick.app` — отдельное приложение, работает без DAW.

На этом Mac оба плагина уже установлены. В DAW плагин отображается от разработчика **MyDarknessDays** (Logic: Audio Units → MyDarknessDays → PowerKick).

### Windows вручную

Распакуйте `Сборки/PowerKick-1.0.0-Windows-x64.zip` и скопируйте папку `PowerKick.vst3` целиком в `C:\Program Files\Common Files\VST3\`. Подробности — в `УСТАНОВКА.txt` внутри архива.

## Управление

| Ручка | Что делает |
|---|---|
| TUNE | Основная нота тела после спада высоты, ±12 полутонов от A1 (55 Гц) |
| DECAY | Длина бочки, 60–1500 мс |
| PUNCH | Сила начального удара: глубина и скорость спада высоты, транзиент |
| BODY | Плотность: как долго держится тело и насколько оно насыщено |
| CLICK | Громкость верхнего щелчка; под ручкой выбор типа: Soft, Sharp, Metal, 909 Noise или FM Blip |
| DRIVE | Перегруз с oversampling (по умолчанию 4x, в ADVANCED 2x/4x/8x — настройка качества экземпляра: пресеты, A/B и VARIATION её не меняют); под ручкой алгоритм: Saturate, Clip или Industrial. Низ защищён, середина автоматически вычищается |
| CHARACTER | Сила выбранной окраски: DEEP, PUNCHY, DARK, HARD или RAW |
| RUMBLE | Рамбл, синхронный с темпом (1/16, 1/8, 3/16) и приглушаемый под каждым ударом |
| OUTPUT | Выходная громкость |
| WIDTH | Ширина только верхних гармоник; саб и тело остаются по центру |
| DELAY | Временной сдвиг между L и R в расширенной части, 0–15 мс (работает при WIDTH > 0) |
| SPLIT | Частота, выше которой начинается расширение, 150–2000 Гц; саб ниже 120 Гц всегда моно |

- **Пресеты:** щелчок по имени пресета открывает панель поверх ручек. Вложенных подменю нет:
  - слева жанры с числом пресетов и «My presets» (свои пресеты);
  - сверху поиск (слова имени, жанра или типа) и типы звука (Short, Long, Clean…), можно включить несколько;
  - справа весь подходящий список: по жанру, внутри жанра по алфавиту;
  - щелчок по пресету загружает его, при включённом AUDITION удар сразу звучит; стрелки ↑/↓ листают список; Enter, Esc или CLOSE закрывают панель;
  - кнопки < > в шапке листают пресеты в том же порядке, при открытой панели — внутри отфильтрованного списка.
- **Двойной щелчок** по ручке возвращает значение по умолчанию.
- **Shift при перетаскивании** включает точную настройку.
- **Щелчок по форме сигнала** проигрывает удар (как PREVIEW), **перетаскивание** в DAW вставляет удар как WAV 24-bit.
- **Меню «…»:**
  - сохранить, переименовать, удалить, импортировать и экспортировать пресет;
  - Mono Check (при включении на экране появляется надпись MONO CHECK);
  - игра по нотам (Key tracking);
  - чувствительность к velocity;
  - запасной темп для хоста без BPM.
- **VARIATION** меняет тембр, сохраняя ноту, режим Character, стерео и воспринимаемую громкость. **UNDO** отменяет вариацию.
- **A/B:** при первом нажатии B становится копией A. Кнопка A>B копирует A в B.
- **ADVANCED** открывает панель поверх ручек:
  - PITCH — глубина и время спада высоты, форма спада, медленный спад в хвосте, корневая нота для key tracking;
  - CLICK / RUMBLE — тон щелчка и длина рамбла;
  - BODY — вырез середины тела, чистый саб-слой, начальная фаза;
  - DRIVE — перегруз атаки, velocity → DRIVE, mod wheel → DRIVE; LEVEL — чувствительность к velocity;
  - LENGTH — удар заканчивается к 1/4, 1/8 или 1/16 при текущем темпе; RUMBLE MODE — Classic или Reverb; CHOKE — отпускание ноты обрывает удар за 4 мс (длина ноты = длина бочки); OVERSAMPLING — 2x, 4x или 8x.

  Всё, кроме уже заданных пресетом значений, по умолчанию нейтрально: звук пресетов от панели не меняется.

Пользовательские пресеты хранятся в `~/Documents/PowerKick/Presets` в виде файлов `.pkpreset` (XML, UTF-8, без абсолютных путей), поэтому их можно переносить между macOS и Windows.

## Близость к референсам

300 заводских пресетов (Techno 30, Hard Techno 110, Schranz 100, Industrial 56, Rave / Hard Dance 4), в меню разложены по группам Short / Long / Rumble / Wide / Crushed / Driven / Clean. Они не придуманы вручную: они подогнаны к типичным бочкам из 556 референсов (паки TSOHT, Techno / Hard Techno / Schranz / Industrial). Внутри каждой категории `Tools/fit_kicks.py` находит характерные бочки (k-medoids) и подбирает параметры синтеза так, чтобы совпали огибающая, спад высоты, спектр каждой фазы удара и стерео. Сравнивается форма, нормированная по пику, а не громкость мастеринга. Звук референсов в плагин не попадает.

Плотность даёт сам синтез, без лимитера: длинное ровное тело, перегруз с защитой саба и вырез середины в теле. Для сравнения: пик к RMS удара у пресетов в среднем около 7 дБ, у референсов около 6 дБ. Пресеты выдают пик −1 dBTP (true peak — с учётом пиков между отсчётами, с 24.10.2026), чтобы осталось место для сведения и экспорт в MP3/AAC не перегружался.

Все пресеты остаются в регистре бочки: высота тона на 30–60 / 60–120 / 120–200 мс не выше 170 / 100 / 80 Гц (p90–p97 референсов). Иначе бочка звучит как нота синта. Это проверяет `Tools/pitch_guard.py audit` и тест в `powerkick_tests`.

**«Синт» и «колокольчики» (исправлено 23.10.2026).** По прослушиванию Романа у 90 пресетов середина 300–3000 Гц после удара звенела как нота: у настоящих бочек там шум. В подбор добавлен признак тональности середины (плоскость спектра в 15–60 и 60–140 мс, `Tools/kick_features.py`), и 88 пресетов переподобраны к своим референсам (`Tools/refit_kicks.py`): нота, жанр и группа сохранились, громкость — по той же норме −1 дБFS. Теперь у всех 88 тональность и звон в пределах референсов жанра (тональнее 10 % референсов или звонче 95 % — ни одного; было 81). 18 пресетов, чей референс сам звенел сильнее 90 % бочек жанра, подогнаны к ближайшему более шумному. 68 из них получили новые имена по звуку (список — `Исследования/2026-10-23 — Синтовые пресеты кика/Переименования.txt`; новые имена не повторяют ничьих прежних): прежнее имя указано в комментарии строки в `Source/Presets.cpp`. Rawstyle Screech и Gabba Lite (Rave) звенят по замыслу жанра и не менялись. Прежняя библиотека — `Исследования/2026-10-23 — Синтовые пресеты кика/Presets.cpp.before-refit`.

## Как устроен звук

```
Голос (до 2, мягкий перезапуск 4 мс):
  тело = синус со спадом высоты (pitch envelope) + удар PUNCH + насыщение BODY
  щелчок = Soft (шум + блип) | Sharp (ВЧ-шум) | Metal (кольцевая модуляция 6 синусов)
→ + Rumble (задержка по темпу → гребенчатые фильтры → НЧ → дисторшн → приглушение под ударом)
→ Drive с oversampling 2x/4x/8x → вырез середины по DRIVE → защита саба (вычитающий раздел 90 Гц: низ + верх = вход, без задержки низа)
→ Character EQ (4 полосы, плавные переходы) → DC-фильтр → Output
→ Stereo Engine → мягкий ограничитель (−0,9 dBFS → ≤ 0 dBFS)
```

**Повтор удара.** Если новая нота приходит, пока прошлый удар ещё звучит (роллы), весь выход за 1 мс затихает, тракт очищается, и новый удар звучит точно так же, как одиночный. Поэтому роллы не громче одиночного удара, а громкость пресетов (пик −1 дБFS) задаёт одиночный удар.

**Stereo Engine.** Фазосогласованные кроссоверы LR4 на 120 Гц и на SPLIT (150–2000 Гц, по умолчанию 1 кГц):

- **SUB** (ниже 120 Гц) — строго моно.
- **BODY** (от 120 Гц до SPLIT) — в центре.
- **HIGH** (выше SPLIT) и немного BODY проходят через цепочку allpass-декорреляции и становятся боковым сигналом S. DELAY добавляет к S разность «верх минус верх с задержкой», то есть настоящий сдвиг между каналами. Боковой сигнал дополнительно проходит фильтр верхних частот 8-го порядка на SPLIT.
- Выход: `L = центр + S`, `R = центр − S`.

Поэтому сумма в моно вообще не содержит бокового сигнала: при любом DELAY не появляется гребенчатая фильтрация. Чтобы ширина не работала как прибавка громкости, WIDTH по закону равной мощности немного снимает верх из центра. При WIDTH = 0 каналы L и R совпадают побитово.

## Сборка из исходников

Нужны CMake 3.22+ и Xcode Command Line Tools. JUCE лежит в `third_party/JUCE` (коммит 29396c2).

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
```

```bash
cmake --build build -j
```

```bash
build/powerkick_tests_artefacts/Release/powerkick_tests
```

- `-DPOWERKICK_COPY_AFTER_BUILD=ON` ставит плагины в системные папки после сборки.
- **Windows** (на Windows): Visual Studio 2022, те же команды; соберётся VST3.
- **Windows** (кросс-сборка на Mac): задайте `WIN_LLVM_ROOT` (llvm-mingw), `WIN_SDK` (`xwin splat`) и `WIN_WINE` (обёртка для запуска wine), затем вызовите cmake с `-DCMAKE_TOOLCHAIN_FILE=cmake/windows-clang-msvc.cmake`.
- `powerkick_tests --report` выводит уровни пресетов.
- `powerkick_tests --export <папка>` рендерит все 300 пресетов в WAV.
- `powerkick_wrapper_tests --snapshot <папка>` сохраняет снимки окна (основной вид и ADVANCED) в PNG.

**Установщики:** `bash Tools/make_installers.sh` собирает `Установщики/PowerKick-<версия>-macOS.pkg` (AU, VST3, приложение) и `…-Windows-x64-Setup.exe` (NSIS: `brew install makensis`) из подписанных сборок в «Сборках»; инструкция — `Установщики/УСТАНОВКА.txt`.

**Проверка Windows-сборки без Windows:** `Tools/host_check` (в проекте PowerBass, годится для обоих плагинов) — маленький хост VST3: собирается тем же тулчейном, запускается под Wine, загружает `.vst3` как DAW и проверяет звук на 44,1/48/96 кГц, сохранение состояния, окно плагина (открытие, звук при открытом окне, закрытие). `cmake/patch_juce.cmake` перед сборкой исправляет в JUCE 8.0.12 зависание при закрытии окна плагина в Windows, когда `WaitForVBlank()` не работает (так под Wine).

## Референсы

`Tools/analyze_kicks.py` измеряет готовые бочки: высоту тона, длину, спектр по полосам, стерео по полосам и межканальную задержку. Звук из сэмплов не копируется. Результаты лежат в `Референсы/`: `shots.csv` — 606 бочек из паков TSOHT, `powerkick_demo.csv` — наши пресеты. Подробности — в журнале проекта.
