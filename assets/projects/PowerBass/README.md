# PowerBass

Басовый синтезатор MyDarknessDays для Dark, Hard, Industrial, Underground и Raw Techno, Schranz и Hardgroove. Минимум регуляторов, максимум характера. Это настоящий синтез, без сэмплов.

Форматы:

- **macOS:** AU (для Logic) и VST3, универсальная сборка Apple Silicon + Intel, а также отдельное приложение Standalone. macOS 10.13 и новее на Intel, macOS 11 и новее на Apple Silicon.
- **Windows 10/11 x64:** VST3 и отдельное приложение.

## Установка

**Проще всего — установщики** из папки `Установщики`: `PowerBass-1.0.0-macOS.pkg` и `PowerBass-1.0.0-Windows-x64-Setup.exe`, по одному файлу на систему. Порядок — `Установщики/УСТАНОВКА.txt`.

**macOS вручную.** Из папки `Сборки/macOS`:

- `PowerBass.component` → `~/Library/Audio/Plug-Ins/Components/`
- `PowerBass.vst3` → `~/Library/Audio/Plug-Ins/VST3/`

На этом Mac плагин уже установлен. В Logic: AU Instruments → MyDarknessDays → PowerBass.

**Windows вручную.** Из `Сборки/PowerBass-1.0.0-Windows-x64.zip` скопируйте папку `PowerBass.vst3` целиком в `C:\Program Files\Common Files\VST3\`. Подробности — в `УСТАНОВКА.txt` внутри архива.

## Быстрый путь к басу

1. Выберите пресет.
2. Подберите основу ручкой **SHAPE**.
3. Добавьте металла ручкой **FM AMOUNT**.
4. Задайте движение ручкой **CUTOFF**.
5. Усильте перегруз ручкой **DRIVE**.
6. Поменяйте характер ручками **DARK** и **BITE**.
7. При необходимости расширьте верх ручкой **WIDTH**.

## Регуляторы

Окно разбито на блоки по пути звука: сверху крупная форма волны текущего звука (нота, которую играет PREVIEW; перерисовывается, когда ручки останавливаются; **щелчок по ней проигрывает звук** — MIDI-клавиатура не нужна), справа от неё **MASTER** с индикатором — как OUTPUT в PowerKick, ниже два ряда — **SOURCE → FM → FILTER** и **DRIVE → AMP → STEREO** (стрелки между блоками). В каждом блоке одна крупная главная ручка с оранжевой дугой (SHAPE, FM AMOUNT, CUTOFF, DRIVE, WIDTH), остальные меньше и с нейтральной дугой. Всё, включая подписи и кнопки, масштабируется вместе с окном.

| Блок | Ручки | Что делает |
|---|---|---|
| SOURCE | **SHAPE**, SUB, OSC DRIVE | SHAPE плавно переходит sine → triangle → saw → square (полосно-ограниченные волны). SUB — синус на октаву ниже. OSC DRIVE — насыщение внутри осциллятора |
| FM | **FM AMOUNT**, FM RATIO, FM DECAY, MIX | 2-операторная FM; модулятор с обратной связью. 18 соотношений частот: кратные, дробные, негармонические (×1,41, ×2,76, ×3,14, ×7,13…). MIX — баланс аналогового осциллятора и FM. FM AMOUNT действует и на аналоговый осциллятор, так что металл добавляется при любом MIX |
| FILTER | LP24 / LP12 / BP / HP, **CUTOFF**, RESONANCE, ENV AMOUNT | TPT-фильтр, мягкое отслеживание высоты ноты, огибающая со своим затуханием |
| DRIVE | SATURATE / CLIP / FOLD / DESTROY / CRUSH, **DRIVE**, TONE, MIX, DARK, BITE | Ниже 120 Гц сигнал только мягко насыщается, поэтому саб не превращается в гул. CRUSH — намеренное цифровое разрушение. DARK опускает фильтр и TONE, уплотняет низ-середину (160 Гц), гасит верх. BITE добавляет драйв, резонанс, FM-скрежет и середину 1,8 кГц |
| AMP | ATTACK, DECAY, SUSTAIN, RELEASE, PUNCH, GLIDE, кнопки LEGATO и SMOOTH | Монофонический голос с приоритетом последней ноты. Каждая новая нота начинается с полной атаки: если прежняя ещё звучит (ноты вплотную, длинный RELEASE), она гаснет за 1 мс и тракт начинается заново. PUNCH — короткий удар по высоте и громкости в начале ноты. LEGATO (горит): нота, нажатая до отпускания прежней, продолжает её без новой атаки и скользит при GLIDE; не горит — каждая нота заново, GLIDE скользит всегда. SMOOTH (горит): прежнее поведение до 23.10.2026 — ноты подряд продолжают звук с текущего уровня без новой атаки; по умолчанию выключена, проекты и пресеты без неё тоже получают «выкл» |
| MASTER и STEREO | **MASTER** с индикатором (справа от формы волны); блок STEREO: **WIDTH**, SPLIT, DELAY | Мягкий связанный ограничитель пиков. Всё ниже SPLIT (100–1000 Гц) строго моно; выше — декоррелированный боковой сигнал (`L = M + S`, `R = M − S`). DELAY (0–15 мс) — сдвиг между L и R выше SPLIT; моно-сумма от него не меняется |

- **Панель ADVANCED:**
  - фильтр до или после дисторшна;
  - oversampling 2x, 4x или 8x — настройка качества этого экземпляра: пресеты её не меняют;
  - затухание огибающей фильтра;
  - DETUNE: две расстроенные копии аналогового осциллятора (риз);
  - чувствительность к velocity;
  - диапазон pitch bend.
- **Пресеты:** щелчок по имени пресета открывает панель поверх ручек. Вложенных подменю нет:
  - слева 10 жанров с числом пресетов и «My presets» (свои пресеты);
  - сверху поиск (слова имени, жанра или типа) и типы звука (Reese, FM, Sustained, Plucks), можно включить несколько;
  - справа весь подходящий список: по жанру, внутри жанра по алфавиту;
  - щелчок по пресету загружает его, при включённом AUDITION сразу звучит короткая нота C1; стрелки ↑/↓ листают список; Enter, Esc или CLOSE закрывают панель;
  - кнопки < > в шапке листают пресеты в том же порядке, при открытой панели — внутри отфильтрованного списка.
- **SAVE и меню «…»:** сохранение, переименование, удаление (в Корзину), импорт и экспорт пресетов `.pbpreset`. Это XML без абсолютных путей, файлы переносятся между macOS и Windows. Пользовательские пресеты хранятся в `Documents/PowerBass/Presets`.

**304 заводских пресета** в 10 категориях; внутри каждой — группы Reese / FM / Plucks / Sustained:

- Rolling Techno — 100;
- Dark Underground — 64 (в том числе Reese Core — звук по умолчанию — и его ручные варианты Reese Core Hard и Reese Core Dirty, Dark Pulse с вариантами Dark Pulse Click и Dark Pulse Clip);
- Hard Techno Rumble — 55;
- Raw Analog — 20;
- Acid-Inspired — 13;
- Destroyed — 13;
- Schranz Distorted — 12;
- Metallic — 12;
- Industrial FM — 10;
- Deep Sub — 5.

## Близость к референсам

295 из 304 заводских пресетов подогнаны к типичным басовым лупам из референсов (4 — ручные варианты Reese Core и Dark Pulse, 5 — Deep Sub) (паки TSOHT; для Rolling — пул из 107 лупов, отобранных по ритму) с помощью `Tools/fit_bass.py` и собраны `Tools/build_library.py`. 23.10.2026 по прослушиванию Романа 286 из них переподобраны на нынешнем движке (`Tools/refit_bass.py`): RELEASE не больше 150 мс — в паузе на долю кика бас затихает; без «глухих» сочетаний (TONE ≥ 0,4, DARK ≤ 0,6, срез ≥ 150 Гц); Raw Analog — по новым референсам (басовые синт-линии вместо саб-слоёв). Прежняя библиотека — `Исследования/2026-10-23 — Переделка пресетов/FactoryPresets.inc.before-refit`. Совпадают гармонический профиль относительно ноты, плотность, движение тембра и стерео выше 100 Гц. Ниже 100 Гц бас по заданию строго моно, в отличие от многих широких лупов в паках. Звук референсов в плагин не попадает. Громкость пресетов выставлена на пик −1 дБFS по сетке `Tools/normalize_peaks.py`: два риффа и выдержанная нота на каждом полутоне от E1 до C3, плюс роллы 1/16 и 1/32 при 130–170 BPM. Резонансные пресеты при других нотах и темпах изредка ненадолго заходят в мягкую аварийную защиту (до +0,9 дБ над порогом; задача Т1 плана открыта). Высота тона баса пока не менялась.

## Как устроен звук

```
pitch (glide, bend, punch) → analog osc (morph + FM PM) / FM sine + sub → [filter] → distortion (sub-protected,
TONE, MIX) → [filter] → amp ADSR          — всё это в oversampling 2/4/8x
→ DC-фильтр → DARK/BITE EQ → stereo (моно ниже SPLIT) → MASTER → связанный ограничитель пиков
```

**Плавность и безопасность в реальном времени:**

- все непрерывные параметры сглаживаются (~15 мс);
- смена пресета, типа дисторшна, режима или положения фильтра и oversampling проходит через затухание 4 мс, без щелчков;
- перезапуск звучащей ноты — затухание выхода 1 мс и чистый тракт, без щелчка и без хвоста прежней ноты (как в PowerKick);
- в аудиопотоке нет выделений памяти (это проверяется тестом).

## Сборка

Нужны CMake 3.22+ и JUCE 8 (`third_party/JUCE`).

**macOS:**

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
```

```bash
cmake --build build -j
```

```bash
build/powerbass_tests_artefacts/Release/powerbass_tests
```

**Windows** (на Windows): Visual Studio 2022 и те же команды.

**Windows** (кросс-сборка на Mac):
- Нужны три инструмента:
  - LLVM (llvm-mingw, только clang-cl в режиме MSVC);
  - Windows SDK, скачанный через `xwin splat`;
  - Wine.
- Задайте переменные окружения:
  - `WIN_LLVM_ROOT` — путь к LLVM;
  - `WIN_SDK` — путь к Windows SDK;
  - `WIN_WINE` — обёртка для запуска wine (через неё сборка генерирует `moduleinfo.json`).
- Сборка:

```bash
cmake -S . -B build-win -DCMAKE_TOOLCHAIN_FILE=cmake/windows-clang-msvc.cmake -DCMAKE_BUILD_TYPE=Release
```

```bash
cmake --build build-win -j
```

`powerbass_tests --report` выводит уровни пресетов. `--export <папка>` рендерит рифф каждым пресетом в WAV. `Tools/normalize_peaks.py` выставляет MASTER пресетов по пику (запускать после пересборки тестов).

**Установщики:** `bash Tools/make_installers.sh` собирает `Установщики/PowerBass-<версия>-macOS.pkg` (AU, VST3, приложение) и `…-Windows-x64-Setup.exe` (NSIS: `brew install makensis`) из подписанных сборок в «Сборках»; инструкция — `Установщики/УСТАНОВКА.txt`.

**Проверка Windows-сборки без Windows:** `Tools/host_check` (в проекте PowerBass, годится для обоих плагинов) — маленький хост VST3: собирается тем же тулчейном, запускается под Wine, загружает `.vst3` как DAW и проверяет звук на 44,1/48/96 кГц, сохранение состояния, окно плагина (открытие, звук при открытом окне, закрытие). `cmake/patch_juce.cmake` перед сборкой исправляет в JUCE 8.0.12 зависание при закрытии окна плагина в Windows, когда `WaitForVBlank()` не работает (так под Wine).

## Референсы

`Tools/analyze_bass.py` измеряет басовые лупы: спектр по полосам, стерео по полосам, основную частоту, crest-фактор и постоянную составляющую. Звук не копируется. Результаты лежат в `Референсы/`: 367 басовых линий и 120 rumble-басов из паков TSOHT, а также наши демо.
