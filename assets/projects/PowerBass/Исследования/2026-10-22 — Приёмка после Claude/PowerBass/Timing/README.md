Прямой импульсный замер двух стадий из текущего `BassEngine.h`; внешняя копия открывает private только для доступа, production не изменён. DIST MIX=0 измеряет всепропускающее сложение полос LR4; стерео — моно-сумму при DELAY=0. Файл width0/width1 задаёт WIDTH=0/1. Это измерение конкретных линейных стадий, не суммарное время начала ноты, не задержка MIDI и не компенсация хоста PDC. Активные нелинейности, музыкальное восприятие и вся цепь отдельным этим тестом не доказаны. Архитектуру DIST в этом запуске не меняли: прежний компромисс по разделению саба остаётся открытым.
