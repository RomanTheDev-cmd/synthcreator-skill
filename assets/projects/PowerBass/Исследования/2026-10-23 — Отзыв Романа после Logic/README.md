## 2. «Завис при переключении пресетов»

- Отчётов о зависании Logic (`~/Library/Logs/DiagnosticReports`, `/Library/Logs/DiagnosticReports`) нет.
- `scripts/stress_mode.cpp` (режим `--stress` только во временной копии теста): все 300 пресетов сменяются каждые 120 мс во время ролла, блок 64 и 512, OVERSAMPLE 2x/4x/8x. Худший блок 16–18 % бюджета реального времени, средний 1,6–2,5 %, NaN/inf 0, замолчавших пресетов 0, через 2,5 с после последней ноты тишина. Движок при смене пресета не зависает.
- Найден дефект (обоих плагинов): `applySnapshot` ставит значение по умолчанию каждому параметру, которого нет в пресете, включая OVERSAMPLE; заводские пресеты OVERSAMPLE не задают. Выбранное 2x/8x при смене пресета возвращается к 4x. Уточнено замером при исправлении: задержка меняется только при 2x (4 → 6 сэмплов при 48 кГц), тогда Logic перестраивает компенсацию на ходу; у 4x и 8x она одинакова (6), там переключается только качество. Может давать кратковременную паузу/рывок; в проекте оба баса на 4x, поэтому причиной этого случая не доказан.
- Папки пользовательских пресетов на этом Mac нет — перечитывание диска при каждом шаге (`rescan`) почти бесплатно.
- Неизвестно: что именно «зависло» (интерфейс, звук, Logic). Нужен ответ Романа.
