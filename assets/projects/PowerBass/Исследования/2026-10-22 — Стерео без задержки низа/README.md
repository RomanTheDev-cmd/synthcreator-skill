# Стерео PowerBass без задержки низа — 2026-10-22 (Claude)

**Состояние:** изменение готово и проверено тестами, но **не установлено**. Оно лежит в ветке git
`bass-stereo-centre-without-delay`, основная ветка `main` его не содержит. Причина — громкость пресетов (ниже).

## Что изменено
Раньше центр стерео собирался из полос LR4 на частоте SPLIT: `low + cos(θ)·high`. Сумма полос LR4 — фазовый
фильтр, он задерживал низ: около 3,4 мс на 60 Гц при SPLIT 150 Гц (1,7 мс при 300 Гц).

Теперь центр — сам входной сигнал минус доля верха, ушедшая в боковой сигнал:
`centre = x − (1 − cos θ)·HP(x)`, где HP — критически демпфированный фильтр 2-го порядка на половине SPLIT.
LR4 используется только для бокового сигнала. Подбор фильтра — `centre_design.py`, `centre_grid.py`.

## Проверено
- Тест Codex `testSplitDoesNotMoveTheMonoSignal` (SPLIT не меняет моно-сигнал при WIDTH 0): RED → GREEN.
- `powerbass_tests` 3131/3131, `powerbass_wrapper_tests` 63/63; прежний тест ширины проходит
  (моно ниже SPLIT/2 в пределах 0,3 дБ, ширина не прибавляет громкости).
- 300 пресетов против прежней сборки (`compare_bass_stereo.py`): RMS от 0 до +0,24 дБ, спектр середины —
  медиана 0,12 дБ (90% ≤ 0,28), ширина (side/mid) от −0,29 до +0,11 дБ. Задержка низа ~0,3 мс вместо ~3,4 мс.

## Почему не установлено
Пики меняются сильнее, чем спектр: фаза низа относительно верха другая, гармоники складываются иначе
(`bass_level_grid.py`, сетка нормировки MASTER: 2 риффа на 5 корнях и выдержанные ноты E1–C3).
При нынешнем MASTER: медиана пика −1,27 дБ (звук плотнее), но 47 пресетов поднимаются выше порога аварийной
защиты (до +0,53 дБFS), а 198 оказываются ниже −1,1 дБFS (158 — ниже −2). Значит, нужен пересчёт MASTER.
Роман указал (2026-10-22, через Codex) не менять OUTPUT/громкость пресетов; решение за ним.
