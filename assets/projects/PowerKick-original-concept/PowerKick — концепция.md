# PowerKick — предложение по устройству и интерфейсу

Дата: 2026-10-21. Автор: Codex.
Статус: концепция для обсуждения. Плагин, звуковой движок и графический прототип не создавались. Предложения ниже ещё не приняты Романом.

## 1. Что за инструмент

PowerKick — синтезатор техно-бочек: выбрать пресет, настроить основной тон, длину и удар, добавить нужную агрессию и пространство, играть по MIDI либо выгрузить WAV.

Приоритеты из задания: звук → простота → стабильность. Название — PowerKick; KICKFORGE остаётся только в исходном описании. Проверка доступности названия и товарных знаков не проводилась.

Целевые форматы из задания: AU и VST3; macOS Apple Silicon/Intel и Windows x64; C++/JUCE. Поддержка конкретных ОС, архитектур и DAW должна подтверждаться отдельными сборками и испытаниями.

## 2. Что предлагаю уточнить в исходном задании

1. Развести BODY, DRIVE и CHARACTER. BODY меняет плотность и форму основной части; DRIVE — перегруз; CHARACTER — интенсивность выбранной окраски. BODY не должен просто повторять выходную громкость.
2. Развести PUNCH и CLICK. PUNCH отвечает за начальный низкочастотный удар и его огибающую; CLICK — за верхний щелчок/текстуру. Уменьшение CLICK не должно лишать бочку основного удара.
3. Оставить один основной экран. Скрыть подробные параметры синтеза, служебные настройки и операции с пресетами в соответствующих меню. Не добавлять полноценную страницу расширенного синтеза на первом этапе.
4. Готовить пресеты после проверки движка. Сначала сделать несколько контрастных звуков для проверки диапазона инструмента; затем всю библиотеку из 26 пресетов.
5. Не обещать качество по виду осциллограммы. Слуховое сравнение, проверка в миксе и в моно нужны отдельно.

## 3. Схема основного экрана

Предлагаемый стартовый размер: около 920 × 600 логических точек; окончательный размер выбрать по читаемости в DAW. Масштабирование — через меню.

```text
┌──────────────────────────────────────────────────────────────────────┐
│ PowerKick     ‹  Preset name / category  ▾  ›     A  B  A→B       ⋯   │
├───────────────────────────────────────────────────────────┬──────────┤
│                                                           │ OUTPUT   │
│          Форма последнего удара                           │ −6.0 dB  │
│          (здесь же область Drag WAV)                      │          │
│                                                           │ L/R      │
│  ▶ TRIGGER                                 EXPORT WAV     │ уровень  │
├───────────────────────────────────────────────────────────┤          │
│        TUNE         DECAY         PUNCH         BODY       │          │
│        F1 / Hz      ms            %             %         │          │
│                                                           │          │
│        CLICK        DRIVE         CHARACTER     RUMBLE     │          │
│        %            %             %             %         │          │
│                                                           │          │
│  Character:  DEEP  PUNCHY  DARK  HARD  RAW                  │          │
├───────────────────────────────────────────────────────────┴──────────┤
│  WIDTH  25%    DELAY  2.0 ms     Rumble: BPM sync     VARIATION  ↶     │
└──────────────────────────────────────────────────────────────────────┘
```

Значения на схеме иллюстративные. Это расположение элементов, а не графический макет или работающий интерфейс.

### Иерархия

- Пресет — первое действие сверху, предыдущий/следующий доступны без открытия списка.
- Форма сигнала — один спокойный информационный участок; помогает видеть длину и хвост, не перетягивает внимание с ручек. До первого удара показывается понятное приглашение нажать Trigger.
- Верхний ряд ручек — форма удара: Tune, Decay, Punch, Body.
- Нижний ряд — обработка и характер: Click, Drive, Character, Rumble.
- Пять режимов Character — компактный подписанный переключатель под ручками; активен ровно один. Интенсивность задаёт ручка Character. В режиме 0% окраска должна отключаться, выбранный режим сохраняется.
- Width и Delay — небольшие, но постоянно доступные регуляторы. При Width = 0 Delay сохраняет значение, но не влияет на звук и отображается неактивным.
- Output — отдельный компактный регулятор с числом и стереоиндикатором. Перегруз обозначается явно, а не только цветом.
- Variation — понятная музыкальная вариация текущего звука с отменой. Название поясняет действие лучше, чем безымянный значок кубика.

### Визуальный язык

Матовый тёмный графит, чуть более светлые рабочие поверхности, светлый текст, один тёплый оранжевый акцент. Красный зарезервирован для перегруза и ошибок. Точные цвета и контраст подлежат проверке при визуальной реализации.

Плоские ручки с тонкой дугой значения, минимум обводок и разделителей. Никаких декоративных винтов, бликов металла, свечения, больших градиентов и имитации рэкового прибора.

Один хорошо читаемый шрифт; короткие английские подписи, числа всегда видны. Выбранный режим обозначается также формой/меткой, а не одним цветом. Размер шрифта и целей управления проверить в реальном масштабе DAW.

Изменение ручки вертикальным перетаскиванием; модификатор для точного изменения, двойной щелчок для сброса, редактирование числа с клавиатуры. Tooltip объясняет слышимый результат простыми словами. Фокус клавиатуры видим. Клавиши не должны мешать обычной работе DAW.

## 4. Поведение и дополнительные функции

### Tune и MIDI

Tune показывает основной установившийся тон бочки нотой и частотой. Во время pitch envelope мгновенная частота другая; не выдавать Tune за точную высоту всего удара.

Предложение для стандартного режима: любая MIDI-нота запускает бочку на установленном Tune; velocity меняет динамику по настроенной кривой. Хроматическую игру и чувствительность velocity поместить в меню. Это предложение, не окончательное решение.

### Decay и Rumble

Decay управляет длиной самой бочки. Rumble имеет собственный хвост с синхронизацией к темпу проекта и автоматическим приглушением под следующей атакой. Небольшое меню рядом с Rumble позволяет выбрать ритмическую длину хвоста; отдельные ручки реверберации не нужны на основном экране.

Прослушивание должно работать и при остановленном транспорте. Для отсутствующего темпа хоста нужен понятный запасной BPM в меню. Повторные удары и перекрывающиеся хвосты требуют отдельной проверки.

### Character

- DEEP — акцент на глубине и массе.
- PUNCHY — акцент на пробивном ударе.
- DARK — более сдержанный верх.
- HARD — плотный, жёсткий характер.
- RAW — грубая текстура и индустриальная окраска.

Это целевые музыкальные различия. Не фиксировать конкретные фильтры и алгоритмы до прослушивания. Character допускает согласованное изменение нескольких внутренних параметров, сохраняя понятную роль остальных ручек.

### Stereo

Низ и основная атака должны оставаться по центру; расширение применять к верхним текстурам. Рассмотреть архитектуру с отдельным центральным сигналом и управляемой боковой составляющей вместо задержки всего правого канала. Конкретные фильтры и частоты выбрать после прототипа и измерений.

Delay 0–15 ms — временной разброс только в разрешённой верхней части. При Width = 0 выход должен становиться моно независимо от сохранённого Delay. При Delay = 0 временной сдвиг отключён; Width может работать другим согласованным способом.

MONO CHECK находится в меню, но при включении имеет заметную надпись на главном экране. Это режим прослушивания: формат WAV задаётся явно в экспорте, случайно включённый Mono Check не должен молча менять файл.

Сохранность удара и отсутствие серьёзных провалов в моно — критерии будущих измерений и прослушивания. Фраза «всегда строго моно ниже 120 Hz» требует определения измеримого допуска и переходной области фильтра; одного номинала частоты недостаточно.

### Пресеты, сравнение и вариации

Пресеты: 6 Techno + 6 Hard Techno + 6 Schranz + 4 Industrial + 4 Rave / Hard Dance = 26. В браузере — категории и пользовательские пресеты, операции сохранения/переименования/удаления/импорта/экспорта. Неподдерживаемый или повреждённый файл даёт понятную ошибку без потери текущего звука. Удаление пользовательского пресета требует защиты от случайного действия.

Предлагается переносимый версионируемый формат без абсолютных путей к файлам. Все звуковые параметры, включая Width и Delay, сохраняются. Output тоже сохраняется; необязательная блокировка Output позволяет сравнивать пресеты при текущей громкости.

A/B хранит две настройки, A→B копирует явно. Сравнение на сопоставимом уровне не должно выдавать увеличение громкости за улучшение тембра; метод подбора уровня потребует проверки на коротких импульсах.

Variation по умолчанию сохраняет Tune, Output и выбранный Character-режим, изменяет тембр в ограниченных диапазонах. Изменения отменяются одним действием. Дополнительные блокировки — в меню, без россыпи значков около каждой ручки.

### WAV и Drag & Drop

Экспорт — один удар с текущими настройками, 24-bit, выбор mono/stereo и частоты дискретизации. Учитывать хвост Rumble и Stereo Delay; не обрезать файл по одному Decay. Проверить совпадение звука экспорта и MIDI-рендера при одинаковых условиях.

Форма сигнала становится областью перетаскивания WAV с явной подписью при наведении. Генерация файла не должна блокировать аудиопоток. Совместимость перетаскивания проверяется по каждой DAW, отдельно от кнопки экспорта.

## 5. Как разумно разрабатывать позже

1. Базовый синтез: низ, pitch envelope, Punch, Click, огибающие, MIDI, корректное повторное срабатывание.
2. Несколько контрастных звуков для слуховой проверки: короткий глубокий, пробивной, жёсткий, индустриальный. Это проверочные настройки, не отдельное расширение заводской библиотеки.
3. Drive, Character и Rumble с управлением уровнем. Oversampling включать в нужных нелинейных участках, учитывая нагрузку, фазу и задержку.
4. Stereo с проверкой моно, крайних значений и взаимодействия с перегрузом/хвостом.
5. Реальный интерфейс по согласованной композиции; проверить читаемость и удобство в Logic и остальных целевых хостах.
6. Состояния, переносимые пресеты и полная библиотека 26 пресетов; экспорт и Drag & Drop.
7. Проверка AU/VST3, доступных ОС/архитектур, автоматизации, повторного открытия проекта, разных частот и буферов. Не объявлять неподтверждённую платформу протестированной.

Важный источник: официальная документация JUCE описывает oversampling для нелинейной обработки и компромисс между фильтрами, фазой и задержкой: https://docs.juce.com/master/classjuce_1_1dsp_1_1Oversampling.html . Наличие класса не подтверждает качество звука PowerKick.

## 6. Что считать доказательством качества

- Слух: отдельная бочка и работа в миксе, сравнение на сопоставимом уровне, все режимы Character и крайние положения ручек.
- Сигнал: конечные значения без NaN/Inf, контролируемый выход, отсутствие непреднамеренных разрывов огибающей, оценка алиасинга, бокового сигнала внизу и mono sum.
- Поведение: автоматизация без слышимых артефактов, повторные MIDI-удары, velocity, хвосты при смене пресета, сохранение/восстановление и A/B.
- Экспорт: 24-bit, правильные каналы/частота, целый хвост, перенос пресетов между ОС и Drag & Drop в проверенных DAW.
- Интерфейс: чтение на реальном мониторе и масштабе, работа мышью/клавиатурой, видимость активных режимов и ошибок.

## 7. Отчёт текущего этапа

Сделано: изучено исходное описание; предложены роли управления, схема одного экрана и порядок будущей разработки. Исходное описание сохранено рядом без изменений.

Проверено: соответствие схемы перечню 11 регуляторов; арифметика библиотеки пресетов; официальный источник JUCE по oversampling; наличие и повторное чтение файлов концепции.

Не проверено: звук, CPU, задержка, mono compatibility, качество пресетов, GUI в DAW, контраст и читаемость реального окна, сборки и экспорт. Реализации пока нет.

Сомнения и недостатки: 11 регуляторов вместе с браузером, экспортом и сравнением потребуют проверки плотности реального интерфейса. Stereo Delay и сильный Drive — основные кандидаты на слуховые и измерительные проблемы. Название PowerKick не проверено на доступность. Текстовая схема не является визуальным макетом.
