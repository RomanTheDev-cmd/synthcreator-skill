# SynthCreator 1.0.0

Отдельный приватный плагин для проектирования и разработки аудиосинтезаторов. Создан 2026-10-25 (Codex) по запросу Романа на основе опыта PowerKick и PowerBass.

[Открыть плагин](https://chatgpt.com/plugins/plugins_6addce3195e88191b68b1b3fd0f55935).

Внутри: один общий навык SynthCreator, шесть тематических справок и машинный манифест, 969 файлов собственных исходников/проверок/текстовых исследований обоих проектов и исходной концепции. Покрыты DSP, Drive/Fold, MIDI/атака/задержка, mono/stereo, UI/preview, подбор/миграции пресетов, сборки, installed-AU audit и установщики.

Материалы текущих рабочих проектов отделены от раннего плана: PowerKick — 300 пресетов, PowerBass — 304 на дату снимка. Старые тесты не объявляются новыми результатами; сохранены открытые ограничения и авторство исторических записей Claude/Codex.

Вызов в Codex/Claude: `$synthcreator`. В ChatGPT выберите плагин SynthCreator и сформулируйте задачу, например «Продумай новый басовый синтезатор, пока без кода» или «Найди причину щелчка и предложи проверку установленного AU».

Единый локальный источник: `Служебное/Созданные навыки/synthcreator`. Кодовые примеры и исследования внутри плагина — архивный материал; внешние среды, JUCE, коммерческие reference WAV, бинарники и установщики в пакет не входят. Сборка/DAW требуют доступного локального окружения.

Проверены: структура JSON/YAML, официальный валидатор навыка, хеши файлов и ZIP, отсутствие совпадений известных шаблонов ключей, независимый сценарий поиска/применения знаний, обе локальные ссылки и сохранённые файлы плагина в аккаунте. Структурная проверка не доказывает всё поведение навыка.

Не проверены: свежий запуск через UI ChatGPT после установки, новый процесс Claude, полный цикл создания/сборки/установки нового аудиосинтезатора и слуховая оценка. Исходные PowerKick/PowerBass в этой задаче не менялись, аудиотесты не запускались.
