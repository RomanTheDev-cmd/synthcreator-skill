# Интерфейс синтезатора

Текущие примеры: `assets/projects/PowerKick/Source/PluginEditor.*`, `assets/projects/PowerBass/Source/PluginEditor.*`, README и журналы обоих проектов.

## Принятые решения Power-серии

- Современный сдержанный монохромный интерфейс. Оранжевый акцент ранней концепции Codex не является правилом реализованных продуктов.
- Форма звука наверху, рядом Output/Master и уровень. Preview доступен без MIDI-клавиатуры: Роман явно сообщил, что ею не пользуется. Клик по waveform проигрывает звук.
- Форма представляет текущую настройку/offline render, обновляется после остановки ручек. Она не обязательно является live scope; подпись/состояния не должны вводить в заблуждение.
- Главные ручки следуют музыкальной задаче. Технические настройки — в дополнительной панели с понятным входом, без постоянной стены параметров.
- Браузер — единая панель с жанрами, количеством, типами, поиском и audition. Стрелки/Enter/Esc работают последовательно. Переключение пресета с закрытым браузером и внутри фильтра должно иметь понятный порядок.
- Число ручки видно; Shift — точная настройка, двойной щелчок — сброс; состояния A/B, изменённый звук, Mono Check и перегруз должны быть очевидны.

Не копируй число ручек, размещение блоков и тему без проверки новой задачи. Для нового синта сначала определи типичный путь пользователя и какие 3–5 действий он делает чаще всего. Уточнение одного отсутствующего факта полезнее навязанной дизайн-анкеты.

## Проверка

Посмотри на реальный render окна в целевом размере и масштабе DAW, проверь обрезание подписей, popup/overlay, клавиатурный фокус, wheel/drag, закрытие окна при звучании и сохранение размера. Статическая геометрия не доказывает удобство.

Снимки старого окна — исторические примеры. Для правки GUI проверяется текущий сборочный артефакт; использование только screenshot из другой версии не является визуальной проверкой результата.

При доступности используй профильный навык дизайна/UX для существенной интерфейсной задачи. Отсутствие дополнительного навыка не блокирует простой необходимый интерфейс.
